KCOM Database Hosting

Where the PostgreSQL database lives. All three run standard Postgres, so the Hono API and Drizzle work the same on each, and moving later is a dump-and-restore.

How big is this site's data?

  • Possibly 3,000–4,000 capsules (one a day for 10+ years), 10 blog posts, a few dozen pages: still well under 100 MB of text.
  • Images live in Cloudinary, not the database.
  • Traffic is modest and read-heavy; the public site can cache pages, so the database sees light load.

Any of the three handles this easily. The choice is about cost, convenience and where the API runs.

Recommendation: Neon Free, with our own nightly backup.

Neon wakes up by itself; a paused Supabase project takes the site down until someone restores it. Neon's managed Better Auth also matches the login library we chose. Keep public pages cached so the database can sleep and stay inside 100 compute-hours. If we outgrow it, Neon Launch (~$15–20) costs a little less than Supabase Pro ($25), though Supabase includes daily backups in that price.

Earlier recommendation: Railway, if the API also runs there. Otherwise Neon.

This decision is tied to hosting. With Railway the database, Hono API and admin sit together on one private network with one bill, and cost stays around $5–15/month. If the API ends up on a serverless platform such as Cloudflare Workers, Neon fits better and its free tier likely covers this site.

Supabase is solid, but its main extras (auth, storage) overlap with what we already picked, so you'd pay $25/month for features you don't use.
